# SymVizCrystal

SymViz 是一个面向晶体学与结构化学的交互式可视化工作台。它可以读取常用结构文件，显示晶胞、化学键与对称元素，并对空间群、点群、Wyckoff 位置、等价原子、无序和氢键进行检查。

当前版本：`v0.1.3`

## v0.1.3 主要功能

- 读取 CIF、SDF、MOL、XYZ、MOL2 与 PDB。
- 三维晶体结构、完整分子、超胞、坐标轴和后景 Z fade。
- 空间群操作、点群特征标表、Wyckoff 信息和等价位置映射。
- 无序字段、占有率一致性和 split-site 候选分析。
- 氢键候选、几何参数、约化晶胞、Madelung 静电能、粉末衍射和模型密度图。
- Gaussian 输入生成、本机任务队列和 `.log` / `.out` 结果解析。
- Gaussian Cube 读取以及正、负等值面的交互式三维显示。
- Electron 桌面模式，可自动检测 Gaussian 16 并直接提交任务，无需桥接器地址或访问令牌。
- Multiwfn 桌面工作台：预设分析、自定义命令脚本、串行队列、实时输出、产物管理和独立 Cube 三维可视化窗口。
- Quantum ESPRESSO 周期模型输入生成、本机任务队列、实时输出和结果摘要。

## 本地启动

需要 Node.js `>=22.13.0`。

```powershell
npm install
npm run dev
```

构建与测试：

```powershell
npm run build
npm test
```

## 启动桌面版

如果电脑没有全局安装 Node.js / npm，直接双击项目根目录中的 `启动 SymViz 桌面版.cmd`即可。该启动器使用项目自带的 Electron，不需要 `npm`。`desktop/启动 SymViz.cmd` 也可以双击启动。

桌面版会先构建界面，然后打开独立的 SymVizCrystal 窗口：

```powershell
npm run desktop
```

开发模式：

```powershell
npm run desktop:dev
```

在桌面版中打开“量化 → 队列”，SymViz 会自动检测 `C:\G16W`。如果 Gaussian 安装在其他位置，点击“选择 Gaussian 文件夹”，选择包含 `g16.exe`、`formchk.exe` 和 `cubegen.exe` 的目录即可。随后可以直接点击“本机运行”。

桌面任务默认保存在“文档 → SymViz Gaussian Jobs”，重新打开 SymViz 后仍可看到历史任务。

## 桌面版使用 Multiwfn

将官方 Windows 版 Multiwfn 文件夹放在 SymViz 项目根目录旁或根目录内；当前工作区中的 `Multiwfn_2026.7.15_bin_Win64` 会被自动发现。也可以在“工具 → Multiwfn 波函数分析”中手动选择包含 `Multiwfn.exe` 的目录。

工作台支持 `.fch` / `.fchk`、`.wfn` / `.wfx` / `.mwfn`、Molden、Gaussian 输入输出、Cube 以及常用结构文件。内置结构摘要、AIM 拓扑、ESP 极值、RESP 电荷、电子密度 Cube和静电势 Cube 批处理入口，也可直接输入 Multiwfn 菜单命令脚本以使用其他分析。RESP 的标准结果是 `.chg`，本身不会自动生成 Cube；可在已完成的任务卡片中继续生成 `density.cub` 或 `totesp.cub`。任务在本地串行执行，实时输出与生成文件保存在“文档 → SymViz Multiwfn Jobs”。Cube 产物可在独立的 SymViz 三维窗口中查看正、负等值面。

Multiwfn 不随 SymViz 仓库分发；请遵守其许可证，并在使用结果发表论文时按 Multiwfn 官方要求引用：Lu & Chen, *J. Comput. Chem.* **33**, 580–592 (2012)；Lu, *J. Chem. Phys.* **161**, 082503 (2024)。

## 桌面版使用 Quantum ESPRESSO

Quantum ESPRESSO 用于周期性晶体计算；Gaussian 仍用于孤立分子或分子簇计算。SymViz 不包含 Quantum ESPRESSO，也不会自动下载计算程序或赝势文件。

Windows 推荐通过 WSL2 Ubuntu 运行 Linux 版 Quantum ESPRESSO。在 Ubuntu 中安装：

```bash
sudo apt update
sudo apt install -y quantum-espresso quantum-espresso-data-sssp
```

重新启动 SymViz 后打开“量化 → 周期 DFT”，程序会自动检测 WSL 发行版、`/usr/bin/pw.x` 和系统 SSSP 赝势，不需要手动填写 Linux 路径。也可以覆盖选择：

- Quantum ESPRESSO 程序目录：包含 `pw.x` 或 `pw.exe` 的目录，也可以选择其上一级安装目录。
- 赝势目录：包含所需 `.UPF` 文件的目录。

首版支持 `SCF`、`relax` 和 `vc-relax`，由 CIF 的完整周期晶胞生成 `ibrav = 0` 输入，并提供 PBE、D3(BJ)、平面波截断能、k 点和占据方式设置。提交前会检查元素与赝势是否一一对应；含部分占有率或未解决无序的模型会被阻止直接计算。

任务默认保存在“文档 → SymViz Quantum ESPRESSO Jobs”。队列当前一次运行一个 `pw.x` 任务，并在 SymViz 中持续显示标准输出。WSL 模式会把所需 UPF 暂存到 Windows 任务目录；点击取消会先终止 Linux 进程组，再清理对应的 Windows `wsl.exe` 进程树。

Ubuntu 软件仓库中的 QE 6.7MaX 用于首轮 SCF 与结构优化联调。正式 Berry-phase 极化计算前应升级至当前稳定 QE 7.5，并重新完成赝势、截断能和 k 点收敛测试。

自发极化 `P_s` 将在后续小版本中基于 Berry phase 工作流加入。它需要同一赝势、截断能、k 点和晶胞约定下的极性态与中心对称参考态，不能由单个优化结构直接可靠给出。

## 网页版连接本机 Gaussian 16

SymViz 不包含 Gaussian，也不会绕过 Gaussian 的安装或许可。用户需要在本机安装并获授权使用 Gaussian 16。

默认安装目录为 `C:\G16W`。如安装在其他位置，可先设置：

```powershell
$env:SYMVIZ_GAUSSIAN_ROOT="D:\Gaussian\G16W"
```

随后在项目目录运行：

```powershell
npm run gaussian:bridge
```

保持该终端开启，并把终端显示的访问令牌粘贴到 SymViz 的“量化 → 队列”面板。桥接器只监听 `127.0.0.1`，计算输入、输出、检查点和 Cube 文件保存在本机；默认不会上传到 SymViz 网站或第三方服务器。

可选环境变量：

- `SYMVIZ_GAUSSIAN_ROOT`：Gaussian 16 安装目录。
- `SYMVIZ_GAUSSIAN_WORKDIR`：本地任务目录。
- `SYMVIZ_GAUSSIAN_PORT`：桥接端口，默认为 `8765`。
- `SYMVIZ_GAUSSIAN_TOKEN`：固定本地令牌；未设置时每次启动随机生成。

## 主界面的空间群对称操作演示

点击主菜单或三维视图区页签中的“空间群演示”，也可从“工具 → 空间群对称操作演示…”进入。演示直接在 SymViz 主界面内展开，包含全部 230 类空间群、4425 个代表操作，可按 32 个点群或三个互斥类别筛选：68 类极性空间群、92 类中心对称空间群，以及 70 类非中心对称且非极性的空间群。此前的 P1、P2₁、Pn、P2/n 演示均保留在统一目录中。

- 按类别或点群筛选后选择空间群，再选择代表操作；页面同时显示 `(x, y, z)` 的坐标变换式、对称元素位置和映射过程。动画旁的文字面板解释当前操作的旋转、反射、反演及平移步骤；窄屏时面板排在动画下方。
- 有反演中心的空间群在图中显示红色亮点，并提供分数坐标提示。显示范围为所选常规晶胞的闭合边界；位于顶点、棱、面上的中心与相邻晶胞共享，不表示不同晶胞的中心数量可以直接相加。
- 使用“重播映射”或拖动进度条查看过程；可拖动模型改变视角，或沿 a、b、c 轴观察。“连续执行两次”用于查看操作的复合结果，操作列表另提供整数晶格平移示例。
- 切换“等价位置总览”查看常规晶胞内的一般等价位置，展开“全部代表操作”查看完整坐标表。代表操作按整数晶格平移取模，完整空间群另含任意整数晶格平移。
- “当前结构空间群”按当前 CIF 的空间群编号切换演示，支持全部 1–230 的合法编号，包括默认 α-石英的 No.152。缺少有效编号时仍可浏览全部演示，定位按钮禁用并显示原因。演示采用固定表列设定，不改写 CIF 的轴、原点或原子坐标；例如 No.7 使用 Pn 的 b2 设定，可能与当前 CIF 的 Pc 设定不同。R 空间群使用六方 H 设定。
- 点击“返回三维晶体”继续查看原结构。首次载入后，本次会话内来回切换会保留晶体和演示状态，离开演示时暂停播放；演示内也可使用 `Ctrl+O` 打开结构文件。

动画旁增加了全部 230 类的对称投影图，可在“空间群元素”“点群投影”“一般位置”“当前元素”之间切换。图例随图中元素显示，悬停可查看分数位置、高度、旋转阶数、螺旋分量或滑移向量；点击等价方向或位置可关联代表操作。空间群元素图从全部操作及整数晶格平移推导，并裁切到闭合常规晶胞；同位元素与投影重合高度会合并。滑移面使用通用符号 g，具体位移以提示中的矢量为准。点群立体投影会约去平移，不能据它区分 P2 与 P2₁；●/○分别表示上/下半球，圆周仅为赤道，不自动代表镜面。一般位置图的圈/逗号表示手性关系，高度另在提示中列出。这些是本软件注明图例的几何图，不是国际表原版版式。

在演示顶部切换“铁电相变”，或点击主工作区右上角同名按钮，再从“相变类型”选择例子。两个例子分别保留各自的进度和畴取向，切换会暂停播放。

222F1（4/2）模型使用 222 → 1，具体教学空间群对为 P222（No.16）→ P1（No.1）。冷却时三个非恒等 C₂ 操作失效，沿 a、b、c 的三族二重轴消失，恒等 E 和整数平移保留；两相均无反演中心和镜面。可播放冷却/加热、拖动极性序参量、检验每个操作、切换 4 个等价极化取向，并用前后立体投影比较元素。虚线是已失去的轴的参考残影，可关闭。4 个一般取向不构成两对 ±P；原表 222F1（4/2）中的 4 是等价极化方向数，/2 是可重取向类型记号，F 不是面心晶格标记。

mF1（2/2）使用 Pm（No.6，唯一轴 b，镜面平行 ac）→ P1（No.1）教学例。高对称相 m 已是极性点群，允许镜面内的 Pa、Pc；本例取非零镜面内极化，降温时新增法向 Pb，失去一族镜面。两等价取向为 (Pa,+Pb,Pc) 与 (Pa,−Pb,Pc)，不画成总极化完全反向的 ±P 对。可显示/隐藏已失去镜面的参考残影，观察总极化与新增法向分量，并逐项检验 E、m。两相均无反演中心。高对称相是否具有可开关极化须由实际材料证据判断。

两个相变演示的局域偶极统一采用包围示意原子的连通花生状渐变云：蓝色 δ− 表示相对电子富集侧，红色 δ＋ 表示相对缺电子侧。云形随偶极方向和大小变化，沿偶极轴观察时自然缩短为近圆截面；中心示意原子保持在原偶极中心。操作检验像使用相同轮廓的橙色虚线并标明 δ± 方位。云形是极化电荷分布示意，不是计算电子密度或原子轨道。

投影图的 a、b、c 轴名统一置于晶胞投影包围框外的留白带，并用短引线关联；符号旁不重复打印旋转阶数等文字，防止轴名与角点的 2、2₁ 等标签叠在一起。检查覆盖全部 230 类、a/b/c 三个方向的 690 个投影及四种图形模式。

投影图默认显示本软件自绘的“空间群元素”，保留四种交互图形模式、符号图例、操作关联及已修复的轴标间距。界面不再显示国际表原图、原版图例或原版来源入口；构建和运行均不依赖原图清单或 PDF。此前提取的文件和提取脚本仅保留为离线资料。

模型均为对称性教学示意，不指定材料、实测温度或相变动力学；Aizu 记号不唯一指定空间群对。依据见 [Shi 等的原表](https://doi.org/10.1039/C5CS00308C)和 [FZU Aizu 数据库](https://species.fzu.cz/ordinary.php?item=domains)。

动画使用示意基元，过程帧表示几何插值，不表示分子真实运动。旋转反演按先旋转、再对固定点反演的步骤演示；旋转反演固定点用绿色标记，与真实纯反演中心的红点区分。具有旋转反演操作不等于具有独立的反演操作，例如点群 -4、-6 中的非中心对称空间群不会因此显示红色反演中心。

演示使用随应用打包的本地静态文件，无需单独启动 `8770` 服务，也不依赖运行时 Python、Gemmi 或 CDN。开发时执行 `npm run symmetry:build` 可从 `tools/symmetry-demo/` 生成页面资源到 `public/symmetry-demo/`；`npm run build` 会自动执行此步骤。若更新 catalog.json，应先运行 `tools/build-symmetry-element-diagrams.py`（需要 NumPy）重新生成与目录哈希对应的投影元素数据，再打包。构建与测试覆盖目录、元素真实坐标、全部操作动画、相变模型的稳定子群及桌面资源访问。
